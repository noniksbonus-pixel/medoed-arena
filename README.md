# Медоед-Арена

Браузерная многопользовательская top-down игра про медоедов. Клиент работает на HTML5 Canvas и ES-модулях, сервер синхронизирует арену через Socket.IO. Внешние изображения и тяжёлые игровые фреймворки не нужны.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте **http://localhost:3000** в браузере. Для игры по локальной сети откройте тот же адрес с другого устройства, используя IP компьютера с сервером. Интернет-подключение для работы игры не требуется (кроме необязательного шрифта Google; интерфейс использует системный запасной шрифт).

## Управление

- Компьютер: WASD или стрелки — движение; левая кнопка мыши — атака; пробел или правая кнопка — способность.
- Телефон/планшет: джойстик слева, кнопки атаки и способности справа.
- В меню можно выбрать одного из 15 бойцов. Имя сохраняется локально после первого запуска.
- Подойдите к светящемуся значку, чтобы подобрать одно из 23 видов оружия. Убийства и нанесённый урон дают опыт; на новом уровне выберите одну из трёх карт.

## Структура

- `server.js` — Express, Socket.IO, игровая симуляция, проверка атак, выдача опыта и сохранение лидерборда.
- `data/leaderboard.json` — создаётся автоматически, содержит результаты между перезапусками.
- `index.html`, `style.css` — интерфейс, меню и адаптивные мобильные контролы.
- `js/main.js` — связывает интерфейс, ввод, сеть и движок.
- `js/engine.js`, `js/map.js` — Canvas-рендеринг бойцов, карты и подборов.
- `js/net.js`, `js/input.js` — реальное время и управление.
- `js/fighters.js`, `js/weapons.js`, `js/upgrades.js` — каталог персонажей, оружия и карт улучшений.
- `js/ui.js` — экраны меню, выбора бойца, лидерборда, результата и прокачки.

## Технические заметки

Сервер задаёт скорость и позицию, ограничивает координаты мира, проверяет дистанцию и угол атаки, рассчитывает HP/убийства, а клиенту отправляет снимки состояния с частотой 30 Гц (симуляция — 30 Гц). Это базовая защита от простых подмен координат и урона, но не полноценный античит. Для публичного продакшена рекомендуется добавить авторизацию, лимиты соединений, контроль частоты событий и резервное копирование файла лидерборда.
